# Quantum Experiment Results

This repository contains the raw source files, output data, and visual analyses generated from our suite of quantum computing experiments. 

---

### Artifacts Generated

All experiment results are standardized into the following formats for easy parsing and review:

*   **`JSON`**: Raw execution data, measurement counts, and metric logs.
*   **`NumPy Plots`**: Rendered visualizations of probability distributions and performance metrics.
